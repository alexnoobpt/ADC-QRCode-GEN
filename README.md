# qrcodegen

A small Python project.

## Structure

```
QRCODE-GEN/
├── src/
│   ├── __init__.py
│   └── app.py
├── tests/
│   ├── __init__.py
│   └── test_app.py
├── requirements.txt
├── .gitignore
└── README.md
```

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate    
pip install -r requirements.txt
```

## Run

```bash
python -m src.app
```

## Test

```bash
pip install pytest
pytest
```
